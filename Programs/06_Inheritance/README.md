# Inheritance in C++

This section contains C++ programs that demonstrate inheritance and code reusability using object-oriented programming.

The examples cover different inheritance structures and illustrate how derived classes can use the accessible members of base classes.

## Programs Included

1. Single inheritance
2. Multilevel inheritance


## Learning Outcomes

- Understand the relationship between base and derived classes.
- Implement different inheritance models in C++.
- Explore access modes in inheritance.
- Reuse class members through inheritance.
